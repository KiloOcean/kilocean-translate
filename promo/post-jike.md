# 即刻推广草稿（1.3.0 已上架）

自己做了个 Chrome 网页翻译扩展：千浩翻译 · Kilocean Translate（商店已上架 1.3.0）。

用自己的 DeepSeek Key，Key 只存在本机；权限很小（activeTab/scripting/storage + 仅 api.deepseek.com）。支持双语对照、划词确认翻译、动态内容跟译；超长多段落（比如 X 长帖）也能翻。

商店：https://chromewebstore.google.com/detail/lmdbhjngjhlgbpmbjfffegjalchblpke
GitHub：https://github.com/KiloOcean/kilocean-translate

欢迎真实反馈，不刷评。如果用得顺手也可以留个商店评分；吐槽同样欢迎。

> 更新：现已支持 DeepSeek / Kimi 自备 Key；仍不登录、无会员墙、权限最小化。
