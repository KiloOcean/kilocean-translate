## 稍长（Reddit / HN 可用英译版）
I built a Chrome page translator that keeps your own API key local (DeepSeek or Kimi).

Designed against common complaints with “AI webpage translators”:
- No account / no login / no extension subscription wall
- BYOK only — key stays in chrome.storage on your machine
- Minimal permissions: activeTab + scripting + storage; host access only to DeepSeek and Moonshot/Kimi API endpoints (not every site)
- Bilingual / translation-only / original; selection translate asks for confirm before billing; follows newly loaded DOM

Chrome Web Store + GitHub links above. Early days — honest bugs welcome.

Independent project. API usage billed by DeepSeek or Moonshot, not by me.
