# 商店文案（千浩翻译 · Kilocean Translate）

## 简短描述（来自软件包）
Kilocean 千浩翻译：用 DeepSeek API 渐进式翻译网页，并自动跟译新加载内容。权限极小，Key 只存在本机。

## 详细描述
千浩翻译（Kilocean Translate）是 Kilocean / 千浩科技出品的轻量网页翻译扩展：打开外语网页，点一下即可用你自己的 DeepSeek API Key 翻译当前页面，并持续处理动态加载的新内容。

适合谁
- 读英文文档 / 论文 / 技术博客，想要 DeepSeek 级别的译文质量
- 在意隐私：不想把 Key 交给第三方翻译服务
- 需要保存译文：导出 HTML，或打印成 PDF

主要能力
• 整页渐进式翻译，不用等整页一次性完成
• 自动翻译滚动或交互后新出现的内容
• 支持简体中文、繁体中文、英语、日语、韩语
• 支持 DeepSeek V4 Flash（更快）与 V4 Pro（更准）
• 一键恢复原文；可保存 HTML / 打印 PDF
• 自动跳过代码、输入框、链接形态文本和纯数字
• API Key 仅保存在本机；仅在你主动点击后访问当前标签页

怎么用
1. 打开普通网页 → 点扩展图标
2. 填入 DeepSeek API Key（https://platform.deepseek.com/api_keys）
3. 选语言和模型 → 点「翻译当前网页」

隐私：网页文本直达 DeepSeek 官方 API；开发者不收 Key 和内容。本扩展由 Kilocean / 千浩科技独立开发，与 DeepSeek 官方无隶属关系，API 费用按官方计费。
